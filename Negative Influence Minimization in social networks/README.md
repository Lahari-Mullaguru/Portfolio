# Adaptive and Fair Methods for Counteracting Negative Influence in Social Networks

## Overview

This repository contains implementations of algorithms designed to address the **Negative Influence Minimization (NIM)** problem in social networks. These methods aim to counteract negative influence while promoting **fairness** and ensuring **computational efficiency**. The algorithms have been evaluated on both **real-world** and **synthetic** datasets.

## Datasets

### Real-World Datasets

- **Arenas Email Dataset**: Represents an email communication network where nodes are individuals and edges represent email exchanges.
- **Socfb-Caltech36 Dataset**: A Facebook social network dataset representing the social connections of students at Caltech.
- **CA-AstroPh Dataset**: A collaboration network of astrophysicists, where nodes represent researchers and edges represent co-authorship.

### Synthetic Datasets

Four synthetic datasets are generated using the **HICHBA (Highly Clustered Barabasi–Albert)** model, which simulates realistic social networks with scale-free and highly clustered properties.
