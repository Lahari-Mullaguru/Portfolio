**Adaptive and Fair Methods for Counteracting Negative Influence in Social Networks**

**Overview**

This repository provides the implementation of algorithms developed for addressing the Negative Influence Minimization (NIM) problem in social networks. The primary focus of these methods is to counteract negative influence while ensuring fairness and maintaining computational efficiency. The project involves testing these algorithms on both synthetic and real-world datasets.

**Datasets**

**Real-World Datasets**

Arenas Email Dataset: Represents an email communication network where nodes are individuals, and edges represent email exchanges.
Socfb-Caltech36 Dataset: A Facebook social network dataset representing social connections of students at Caltech.
CA-AstroPh Dataset: A collaboration network of astrophysicists, where nodes represent researchers and edges represent co-authorship.

**Synthetic Datasets**
Four synthetic datasets are generated using the HICHBA (Highly Clustered Barabasi–Albert) model, which simulates realistic social networks with scale-free and highly clustered properties.

**Requirements**
Before running the code, ensure you have Python 3.x installed on your system. You can install the required dependencies by running:
---pip install -r requirements.txt

**Project Structure**
main_synthetic.py: Runs experiments on synthetic datasets.
main_email.py: Runs experiments on the Arenas Email dataset.
main_astrophy.py: Runs experiments on the CA-AstroPh dataset.
main_socfb-Caltech36.py: Runs experiments on the Socfb-Caltech36 dataset.
/datasets: Contains the datasets used in the experiments.
/results: Stores the results and visualizations generated by the experiments.
/code: Contains the core code files and utility scripts used across the experiments.

**Running the Experiments**
Synthetic Datasets
To run experiments on synthetic datasets, execute the following command:
---python main_synthetic.py
To run experiments on each of the real-world datasets, use the following commands:
---python main_email.py
---python main_astrophy.py
---python main_socfb-Caltech36.py

**Customization**
If you need to modify the experiments:
 1.Adjust parameters directly in the .py scripts.
 2.Update dataset paths if using custom datasets.
 3.Modify the plotting functions for different visual styles or additional metrics.
