# Regression and Validation 

**Project Type:** Data Science / Machine Learning

## Overview

This project demonstrates a basic workflow for performing regression analysis and validation techniques using a dataset named `swpg.csv`. The focus is on understanding relationships within the data and evaluating the predictive accuracy of a regression model.

## Contents

- Data import and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical description of the dataset
- Regression modeling
- Model validation and performance evaluation

## Dataset

- **File:** `swpg.csv`
- **Shape:** 20 rows × 2 columns
- Contains numerical values used for regression analysis.

## Requirements

The project is implemented in Python using Jupyter Notebook. The following libraries are used:

- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`
- `sklearn`

## Project Overview

###  Regression and Validation
- **Objective:** Utilize the "ftsw" variable to predict the values of "lfgr" using regression models.
- **Tools & Libraries:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
- **Key Features:**
  - Linear Regression
  - Polynomial Regression (Degree 3 and Degree 9)
  - Cross-validation for overfitting detection
  - Comparison of regression models by MSE, RMSE, and R-squared metrics
- **Results:**
  - Detailed analysis and comparison of the performance of different regression models.
  - Visualization of regression fits and error metrics.
