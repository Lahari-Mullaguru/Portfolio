# Business Analytics and Machine Learning Projects

This repository contains two comprehensive projects focused on real-world data analysis and predictive modeling using Python. It includes exploratory data analysis, statistical modeling, and machine learning techniques applied to domain-specific datasets.

---
## 1. Business Analytics

### Overview
This notebook demonstrates how to load and analyze pre-processed training and testing datasets using Python. The data was pre-cleaned using R and saved as CSVs. The objective is to perform descriptive analytics and build predictive models.

### Techniques Used
- Data import and EDA (Exploratory Data Analysis) 
- Statistical modeling and visualization
- Model evaluation metrics

### Key Highlights
- In-depth analysis of business-related structured data
- Comparison of predictions vs. actual outcomes
- Hands-on use of Python data science libraries (Pandas, Matplotlib, Seaborn)

---

## 2. Machine Learning

### Overview
This notebook focuses on applying machine learning techniques to the **Epileptic Seizure Recognition Dataset**. The task involves classifying EEG data to detect seizure patterns.

### Techniques Used
- Data preprocessing
- Feature scaling and encoding
- Model building: Logistic Regression, KNN, Decision Trees, Random Forest, SVM
- Cross-validation and model tuning
- Evaluation using accuracy, confusion matrix, and classification reports

### Key Highlights
- Full ML pipeline for classification
- Performance comparison across multiple models
- Preprocessing pipeline for time-series health data
- High accuracy achieved with ensemble methods
